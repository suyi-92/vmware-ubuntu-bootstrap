## 修复

- 新增 `failure-diagnostics.sh`，入口、bootstrap 和代理子脚本报告启动、阶段、失败位置、函数调用链及状态码，不打印命令参数或配置值。
- ERR 捕获意外非零返回，EXIT 补充显式退出和 nounset；EXIT 无可靠故障行时明确标记 `文件:EXIT`，不虚构行号。
- 保留扫描器、显式代理 curl 和子脚本的原始错误码；回滚处理不能将其改成 1。命令替换继承 `errexit`。
- TCP 发现仍限制到当前 `/24` 或更小，默认每次 1 秒、失败重试一次、32 并发；CLI 参数有上限。HTTP 保留 8 秒连接、20 秒总请求时间和一次条件重试。
- 多个通过 HTTPS 验证的代理仍拒绝自动任选，提示 `--proxy-host`；未硬编码热点地址。
- 修复已有日志目录存在时 `--dry-run` 仍写日志的副作用。本次最初预览产生了诊断日志，但没有应用系统配置；修复后现场比较确认系统代理日志未变化。

## 模式评估与操作边界

频繁换热点时，依赖物理 LAN 的桥接和旧静态地址需要额外维护。NAT/VMnet8 可让 VM 保持独立的虚拟网段，用经宿主确认的 VMnet8 固定地址访问代理；当前提供的例子是 `192.168.136.1:7890`。这需要先规划恢复旧静态配置、在 VMware 控制台更改模式、验证 VM 地址/路由，并核实 Clash 监听及仅限 VMnet8 子网的端口放行。它不能靠改一个代理 IP 就在当前网络上生效。详见 [换网说明](host-ip-change.md#频繁切换热点评估-natvmnet8)。
